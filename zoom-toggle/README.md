# Arranger: Zoom Toggle (prototype)

Needs **Framework: Actions and Menus** to be enabled too.

In Settings > Shortcuts search for **Zoom to Fit Selection (Toggle)** and give it a key (e.g. Z).

- First press: zooms the time axis to the selection (Bitwig's own "Zoom to Fit Selection or Previous")
  and makes the selected track(s) tall.
- Second press: zooms back and returns the track height to what it was.
